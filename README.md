# 工业巡检拍照 App

Industrial inspection photo management app for HarmonyOS Next.

## Target Device

Huawei MatePad Pro 11-inch · 2560×1600 · Landscape only

## Prerequisites

| Tool | Version | Purpose |
|---|---|---|
| DevEco Studio | ≥ 5.0 | Project scaffolding & IDE |
| hdc | bundled with DevEco | Device debugging |
| Claude Code | latest | AI-assisted development |

## Getting Started

1. Open in DevEco Studio: `File → Open → select this directory`
2. Let DevEco Studio initialize the project skeleton (`entry/`, `AppScope/`, etc.)
3. Start Claude Code at this directory root
